# OpenUX

The OpenUX Standard.

The `standard/` directory contains the standard's working documents. The Node.js server and browser editor are at the repository root, and the editor's sample OpenUX project is in `openux/`. Run `npm install` once, then `npm start` to launch the local editor at `http://127.0.0.1:3000/`.

See [Editor Requirements](standard/editor.md) for the current editor behavior and prototype status.
